Why Visual OCR is Required

Lightweight AI browser agents frequently encounter rich web applications, PDF renderers, financial charting dashboards, and graphical interfaces where personal data is rendered as pure image pixels.

  • DOM-only scanning cannot access <canvas> contents.
  • PrivAgent Milestone 3 captures the visible viewport bitmap.
  • On-device WebAssembly OCR recognizes text regions locally.
  • Contextual heuristics detect sensitive patterns (Cards, Emails, Phones, PAN, OTP, CVV).
  • Visual Canvas Redactor applies blackout, blur, or mask before agent transmission.
